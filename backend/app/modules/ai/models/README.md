# Releases locales

Artefactos JSON de parámetros numéricos y vocabulario; nunca pickle/joblib.
`active.json` selecciona la versión revisada en el despliegue. El checksum detecta corrupción,
no autentica al publicador: distribuir únicamente mediante el repositorio/release de confianza.
Reiniciar el proceso al actualizar o revertir el puntero (la carga se almacena en caché).
